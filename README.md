# pywttr-models

[![Downloads](https://static.pepy.tech/badge/pywttr-models)](https://pepy.tech/project/pywttr-models)

Pydantic models for the responses of the [wttr.in](https://wttr.in) weather API, shared by [pywttr](https://github.com/monosans/pywttr) and [aiopywttr](https://github.com/monosans/aiopywttr). They are available there as `pywttr.models` and `aiopywttr.models`, so you don't need to import this package yourself. The fields are described in the [pywttr API reference](https://monosans.github.io/pywttr/api/#response-models).
